# MAVERIX: Multimodal Audio-Visual Evaluation and Recognition IndeX

## Overview

This benchmark evaluates the cross-modal understanding of vision-language models (VLMs) and specifically audiovisual models. The questions were designed in such a way that when only the video is watched or the audio is listened to, it is challenging to answer the question because there is complementary information when paired with information from the other modality. We highlight in our paper that there is still a ways to go until human performance is reached on this benchmark.
